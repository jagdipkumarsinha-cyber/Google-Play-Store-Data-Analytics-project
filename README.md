# Google Play Store Data Analytics Dashboard

## Overview
This repository contains a real-time data analytics dashboard built with Python. It analyzes Google Play Store app metrics, focusing on installations, revenue, user sentiment, and category growth. This project was completed as part of a data science internship.

## Key Features
*   **Time-Gated Access Control:** Charts are dynamically rendered only during specific operational windows (IST timezones).
*   **Data Cleaning:** Robust preprocessing of app sizes (MB), install counts, and revenue calculation.
*   **Interactive Visualizations:** Utilizes `matplotlib` and `Plotly` to display complex, multidimensional data (e.g., dual-axis charts, interactive bubble charts, and stacked area charts).
*   **Advanced Filtering:** Applies multi-layered criteria including text matching, localized translations, and sentiment subjectivity scoring from user reviews.

## Technologies Used
*   **Python 3**
*   **Pandas & NumPy** (Data Manipulation)
*   **Matplotlib & Plotly Express** (Data Visualization)
*   **Streamlit** (Dashboard Hosting)
*   **Pytz & Datetime** (Time-gating logic)
